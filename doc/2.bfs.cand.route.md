Đúng rồi bro – trong codebase này, **mỗi route-plan là một path đơn**, **không phân tách thành multi-path execution như 1inch split routing**. Nghĩa là:

* ✅ Một route chỉ đi qua **1 chuỗi pool liên tiếp** (VD: `A → B → C`).
* ❌ Không có multi-route như: `A → B` (50%), `A → D → C` (50%).

---

## 🧠 Cách tạo `route candidate list` – chính xác trong code

### 📁 Vị trí code:

```
src/routers/alpha-router/functions/compute-all-routes.ts
```

### 🎯 Mục tiêu:

Tạo danh sách tất cả các path (route) từ `tokenIn` đến `tokenOut` trong giới hạn `maxHops` (mặc định 3).

---

## ✅ THUẬT TOÁN ĐƯỢC DÙNG: **Depth-Limited DFS (graph traversal)**

> Mỗi token là node
> Mỗi pool là edge (chứa 2 token)

---

## 🔎 Chi tiết thuật toán trong code

```ts
function computeAllRoutes(...) {
    const routes: Route[] = [];

    function dfs(
        currentToken: Token,
        currentPath: Pool[],
        visitedTokens: Set<string>,
        depth: number
    ) {
        if (depth > maxHops) return;

        for (const pool of poolsByToken[currentToken.address]) {
            const nextToken = getOtherToken(pool, currentToken);

            if (visitedTokens.has(nextToken.address)) continue;

            // New path
            const newPath = [...currentPath, pool];

            if (nextToken.address === tokenOut.address) {
                routes.push(newPath);
            } else {
                visitedTokens.add(nextToken.address);
                dfs(nextToken, newPath, visitedTokens, depth + 1);
                visitedTokens.delete(nextToken.address);
            }
        }
    }

    dfs(tokenIn, [], new Set([tokenIn.address]), 0);

    return routes;
}
```

---

## 🔁 Tóm tắt lại:

| Thành phần                    | Vai trò                              |
| ----------------------------- | ------------------------------------ |
| `poolsByToken[token.address]` | Tạo adjacency list                   |
| `dfs(...)`                    | Đệ quy theo chiều sâu để duyệt graph |
| `depth <= maxHops`            | Giới hạn số lần nhảy (hops)          |
| `visitedTokens`               | Tránh vòng lặp (loop)                |
| `routes.push(path)`           | Lưu path nếu kết thúc tại tokenOut   |

---

## 📌 Ưu điểm của DFS depth-limited:

* Dễ kiểm soát logic mixed route (v2 → v3 → v4).
* Đảm bảo các route được **đi tuần tự**, không lặp token.
* Hiệu quả khi số lượng pool/tokens không quá lớn.

---

## 🧠 Gợi ý nếu muốn nâng cấp:

* Có thể thay thế bằng **Breadth-First Search (BFS)** nếu muốn ưu tiên các route ngắn nhất.
* Hoặc nâng lên **multi-path (partial splits)** nếu muốn bắt chước 1inch-style.
