## ✅ 1. DATAFLOW – TỪ INPUT ĐẾN OUTPUT

```txt
User Input
  ↓
computeAllRoutes(...) ⬅ getCandidatePools(...)
  ↓
baseQuoter.quote(...)  ⬅ chọn quoter theo DEX type
  ↓
evaluateQuoteAndGas(...) ⬅ áp dụng gasModel
  ↓
bestSwapRoute(...) ⬅ chọn route tối ưu theo hiệu quả
  ↓
Output (route + quote + calldata)
```

### 🔹 \[Step 1] User Input

Input đầu vào là:

```ts
{
  tokenIn,          // Token gốc
  tokenOut,         // Token đích
  amount,           // Có thể là exactIn hoặc exactOut
  tradeType,        // TradeType.EXACT_INPUT hoặc EXACT_OUTPUT
  chainId,
  options?: { gasModel, quoteMode, maxHops, ... }
}
```

---

### 🔹 \[Step 2] `computeAllRoutes(...)`

```ts
computeAllRoutes(tokenIn, tokenOut, amount, providers, options)
```

**Logic:**

* Gọi `getCandidatePools(...)` → tìm tất cả pool có thể liên quan đến cặp token đó.
* Tạo route graph → xây dựng **tất cả path khả thi** giữa tokenIn ↔ tokenOut.
* Tối đa `maxHops` (thường 2 hoặc 3).

**Output:**

```ts
RouteWithQuoteRequest[] = [
  {
    route: Pool[],
    quoteRequest: {
      amount, tradeType, slippage, ...
    }
  },
  ...
]
```

---

### 🔹 \[Step 3] `quoteRoutes(...)` qua `baseQuoter.ts`

```ts
baseQuoter.quote(route, quoteRequest)
```

**Logic:**

* Mỗi route được định tuyến qua một quoter đúng loại:

  * `v2-quoter`, `v3-quoter`, `v4-quoter`, `mixed-quoter`
* Trả về: amountIn/out, calldata swap, gasEstimate sơ bộ.

---

### 🔹 \[Step 4] `evaluateQuoteAndGas(...)`

**Logic:**

* Ước tính gas bằng heuristic model:

  * gasModel riêng cho từng DEX type: `v2`, `v3`, `v4`, `mixed`
* Chuyển `gasCost` thành token-value (thường cùng `tokenIn`).
* Tính:

```ts
effectiveQuote = valueOut - gasCost
```

---

### 🔹 \[Step 5] `bestSwapRoute(...)`

```ts
bestSwapRoute(routesWithQuotes)
```

**Logic:**

* Sắp xếp tất cả route theo `effectiveQuote`
* Trả về route tốt nhất

---

### 🔹 \[Step 6] Output trả về

```ts
{
  route: [...],
  amountIn: ...,
  amountOut: ...,
  gasEstimate: ...,
  gasCost: ...,
  methodParameters: {
    calldata,
    value, // for ETH
  }
}
```

## ✅ 2. CORE ALGORITHM – CÁCH TÌM ROUTE TỐT NHẤT

### ✅ Thuật toán chính nằm ở:

* `computeAllRoutes.ts`
* `quoteRoutes.ts`
* `bestSwapRoute.ts`

---

### 📌 A. **Tìm route khả thi** (`computeAllRoutes`)

Giống như BFS trong đồ thị:

```ts
- Khởi tạo từ tokenIn
- Với mỗi hop:
    - Duyệt pool có token hiện tại
    - Tạo path mới nếu pool chứa token chưa có trong path
- Dừng khi tới được tokenOut hoặc đạt maxHops
```

✅ Cho phép MixedRoute (v2 → v3 → v4...): route hỗn hợp từ nhiều loại DEX.

---

### 📌 B. **Quote từng route** (`quoteRoutes`)

* Gọi quoter tương ứng với route (v2-quoter, v3-quoter,...)
* Tính toán swap:

  * `amountIn → amountOut` (EXACT\_INPUT)
  * `amountOut → amountIn` (EXACT\_OUTPUT)

---

### 📌 C. **Ước tính chi phí gas** (`gas-model`)

Áp dụng heuristic gas model:

```ts
gasCost = gasEstimate × gasPrice
effectiveQuote = quoteValue - gasCost
```

✔ Có nhiều model tùy theo route:

* `v2-heuristic-gas-model`
* `v3-heuristic-gas-model`
* `mixed-route-heuristic-gas-model`

---

### 📌 D. **Chọn route tốt nhất** (`bestSwapRoute`)

```ts
- Sắp xếp tất cả routes theo effectiveQuote giảm dần
- Trả về route đầu tiên (tốt nhất)
```

## 🎯 Tóm tắt

| Giai đoạn     | Vai trò                   | Thuật toán                 |
| ------------- | ------------------------- | -------------------------- |
| Tìm pool      | Lọc graph theo token pair | Duyệt all pools liên quan  |
| Tìm route     | Tạo graph BFS/DFS         | BFS với maxHops            |
| Quote         | Gọi quoter từng DEX       | Hàm toán học per DEX       |
| Gas Model     | Ước tính chi phí gas      | Heuristic model            |
| Chọn tốt nhất | Tối ưu hiệu quả thực nhận | Sort theo `effectiveQuote` |
