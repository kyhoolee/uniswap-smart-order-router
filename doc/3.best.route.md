## 🔎 Chi tiết từng bước

---

### 🔹 1. `quoteRoutes(...)`

File: `quoters/index.ts`

**Mục tiêu:** gọi đúng `Quoter` tương ứng để:

* Tính `amountIn`, `amountOut`.
* Encode `methodParameters`.
* Ước lượng `gasEstimate`.

```ts
// Gọi quoter tương ứng (v2, v3, v4, mixed)
const quoter = getQuoterForRoute(route)
const quoteResult = await quoter.quote(route, quoteRequest)
```

✅ Output mỗi route:

```ts
{
  amountIn: BigNumber,
  amountOut: BigNumber,
  gasEstimate: number,
  methodParameters: { calldata, value },
  route: Route
}
```

---

### 🔹 2. `evaluateQuoteAndGas(...)`

File: `quoters/model/results/get-quotes-result.ts`

**Mục tiêu:** chuyển đổi gasEstimate → chi phí thực tế, tính điểm hiệu quả (`effectiveQuote`)

```ts
gasCost = gasEstimate * gasPrice

// Nếu là tradeType.EXACT_INPUT:
valueOut = amountOut - gasCostInOutToken
// Nếu là tradeType.EXACT_OUTPUT:
valueIn = amountIn + gasCostInInToken

effectiveQuote = (EXACT_INPUT) => valueOut
               = (EXACT_OUTPUT) => -valueIn
```

✅ Đây là điểm cực kỳ quan trọng:

* Không chỉ so sánh `amountOut`, mà còn trừ **chi phí gas**
* Tính theo token thực tế, có thể là `tokenIn` hoặc `tokenOut`

---

### 🔹 3. `bestSwapRoute(...)`

File: `functions/best-swap-route.ts`

```ts
function bestSwapRoute(routes: RouteWithValidQuote[]) {
    return routes.reduce((best, current) => {
        if (!best) return current;
        return current.effectiveQuote.gt(best.effectiveQuote)
            ? current
            : best;
    }, undefined)
}
```

✔ Đây là một phép **reduce để tìm max**, rất rõ ràng và hiệu quả.

## 🧩 Vấn đề thực tế:

> Muốn đánh giá hiệu quả `route`, ta cần biết:

```ts
effectiveQuote = valueOut - gasCost
```

Nhưng:

* `gasCost` được tính bằng **base coin (ETH, BNB, MATIC, …)**.
* Trong khi `valueOut` là bằng `tokenOut`, hoặc cần quy đổi `gasCost` sang `tokenIn/tokenOut`.

---

## ✅ 1. Giá trị gas cost ban đầu

Từ bước `quote`, ta lấy:

```ts
gasEstimate: number // đơn vị: gas units (e.g. 120,000)
gasPrice: BigNumber // đơn vị: wei per gas unit (e.g. 30 gwei)
```

Từ đó:

```ts
gasCostNative = gasEstimate × gasPrice
```

→ Đơn vị: ETH, BNB, AVAX, …

---

## ✅ 2. Chuyển `gasCostNative` → `tokenIn` hoặc `tokenOut`

### ⬇️ Code chính nằm ở:

```ts
src/routers/alpha-router/functions/quoters/model/results/get-quotes-result.ts
```

### ⚙️ Logic thực hiện:

Dựa trên cấu hình gọi là **Gas Cost Conversion Mode**, hệ thống sẽ:

* Gọi `onChainQuoteProvider` để query tỷ giá **baseCoin/tokenX**.

Ví dụ:

```ts
// Nếu cần so sánh với tokenOut:
tokenOutPerBaseCoin = getQuote({
  tokenIn: BASE_COIN,
  tokenOut: tokenOut,
  amountIn: gasCostNative
})
```

Từ đó:

```ts
gasCostInTokenOut = tokenOutPerBaseCoin * gasCostNative
```

> Lưu ý: nếu không có direct pool BASE ↔ tokenOut, hệ thống có thể quote qua DEX hoặc skip estimation.

---

## ✅ 3. Tùy theo `tradeType`, hệ thống so sánh:

### 👉 `EXACT_INPUT`:

* User đưa vào tokenIn cố định.
* Quan tâm đến:

```ts
effectiveQuote = amountOut - gasCostInTokenOut
```

### 👉 `EXACT_OUTPUT`:

* User muốn nhận đúng amountOut.
* Quan tâm đến:

```ts
effectiveQuote = -(amountIn + gasCostInTokenIn)
```

---

## 🧠 Các logic kiểm soát:

| Vấn đề                           | Cách xử lý trong code                                |
| -------------------------------- | ---------------------------------------------------- |
| gas unknown?                     | Dùng `gasModel` heuristic                            |
| tokenIn/tokenOut khác base coin? | Gọi `onChainQuoteProvider` để lấy tỷ giá             |
| tokenIn = base coin?             | Không cần quy đổi                                    |
| quote fail?                      | Có fallback → bỏ qua gas hoặc dùng estimate mặc định |

---

## 📌 Ví dụ minh họa

Giả sử:

* `gasEstimate = 120,000`
* `gasPrice = 30 gwei = 3e-8 ETH`
* `tokenOut = USDC`
* Tỷ giá: `1 ETH = 3000 USDC`

```ts
gasCostNative = 120,000 * 3e-8 ETH = 0.0036 ETH
gasCostUSDC = 0.0036 * 3000 = 10.8 USDC

amountOut = 1000 USDC
effectiveQuote = 1000 - 10.8 = 989.2 USDC
```

---

## 🔒 Lưu ý khi dùng trong thực tế

* Gas price biến động → cần cập nhật thường xuyên (on-chain hoặc oracle).
* Nên cache tỷ giá base coin ↔ stable token để nhanh hơn.
* Trên L2, `gasCost` rất thấp → ảnh hưởng đến effective quote gần như không đáng kể.
